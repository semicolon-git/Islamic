# Signs Around You · آيات حولك

Entry for the **AI Challenge: Serving Islamic Content** (تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي). The build camp runs Oct 4–6, 2026.

- [`docs/review/signs-around-you-review.md`](docs/review/signs-around-you-review.md) is the strategic review of pitch deck v4. It covers:
  - compliance with the challenge's reference pack (levels A–D, the 8 standards, the 12 test questions);
  - a fact-check of the deck;
  - the recommended MVP architecture, the build plan and the demo script;
  - deck edits and judge Q&A.
- [`prep/`](prep/README.md) is the prep-day data kit: pinned Quran, morphology and hadith sources, the verified concept list, an example card and its pre-publish gate.
